# Slay the Spire 2 — State of AI-Agent Tooling (as of 2026-09-21)

Scope: Slay the Spire 2 (StS2) only, not StS1. StS1 tooling (ModTheSpire, BaseMod, CommunicationMod, spirecomm, sts_lightspeed) does not carry over and is excluded except where noted for contrast.

## 1. Engine/language and modding

- StS2 ships on Godot 4, with a Unity→Godot port; all game logic lives in a C#/.NET DLL (`sts2.dll`), not GDScript. [Godot Engine showcase](https://godotengine.org/showcase/slay-the-spire-2/), [Hacker News thread citing dev statements](https://news.ycombinator.com/item?id=40030608)
- Early access launched March 5, 2026 (Windows/macOS/Linux). [Wikipedia](https://en.wikipedia.org/wiki/Slay_the_Spire_II)
- Mega Crit has stated the game was "built with modding in mind" and shipped with an integrated mod loader since day one, but did not advertise it initially "as we knew it still needed some work." Steam Workshop support was officially added June 19, 2026 in Major Update 2 (v0.107.1). [PCGamesN](https://www.pcgamesn.com/slay-the-spire-2/update-2-rng-rework-steam-workshop)
- Mod API namespace: `MegaCrit.Sts2.Core.Modding`, with a `ModInitializer` attribute marking mod entry points. Modding covers manifests, Harmony-style hooks, content registration, Godot `.pck` asset packing, and reuse of native UI. [fresh-milkshake/Modding-Tutorial](https://github.com/fresh-milkshake/Modding-Tutorial), [jiegec/STS2FirstMod](https://github.com/jiegec/STS2FirstMod)
- Community mod managers exist: STS2 Mod Manager (cross-platform, open source) and a Windows-specific mod manager. [Nexus Mods](https://www.nexusmods.com/slaythespire2/mods/165), [mohamedserhan.github.io/sts2-mod-manager](https://mohamedserhan.github.io/sts2-mod-manager/)
- Full game-state read + action-issue via mods is confirmed working in practice: the STS2MCP mod (see §2) hooks the game to expose deck, hand, draw/discard piles, enemy intents/HP, relics, potions, gold, HP, map, current act, ascension level, and profile/compendium data, and can issue actions — play/target cards, choose map paths, use potions, and drive menus (character select, seed entry, multiplayer lobby). [Gennadiyev/STS2MCP](https://github.com/Gennadiyev/STS2MCP)
- Conclusion: yes to both halves of the question — mods can read essentially the full state list requested and can issue programmatic actions, verified via a working third-party mod rather than an official Mega Crit-published API reference (no official API docs page was found; the API surface is being reverse-engineered/used by modders against the shipped mod-loader hooks).

## 2. Headless/fast-forward mode and simulators

- No official headless mode found from Mega Crit. unknown / could not find primary confirmation of an official fast-forward or headless flag.
- Community speed-control mods exist (not headless, just render/tick speed): "No Time To Die" (0.1x–10x speed + overlay), "SpeedX" (2x–20x global speed), "InstantMode" (near-instant animations). [Nexus: No Time To Die](https://www.nexusmods.com/slaythespire2/mods/380), [Nexus: SpeedX](https://www.nexusmods.com/slaythespire2/mods/91), [Nexus: InstantMode](https://www.nexusmods.com/slaythespire2/mods/56)
- Community StS2-specific projects found (verified to exist via GitHub API, repos are non-trivial in size/content, not placeholders):
  - [zhiyue/sts2-rl-agent](https://github.com/zhiyue/sts2-rl-agent) — real, substantial project (63 stars, ~50k LOC per its README, last pushed 2026-05-22). Pure-Python headless reimplementation of StS2 combat/run logic (577 cards, 260 powers, 121 monsters, 290 relics, 63 potions across 5 characters), a Gymnasium training environment, MaskablePPO training scripts, and a C#/Godot bridge mod to run a trained model against the real game over a TCP/JSON protocol. Reports ~1,200 combats/sec and ~28,000 env steps/sec simulation throughput, and ~92% combat win rate for a trained PPO agent on Act 1 Ironclad (see §4).
  - [SJTUHCL10/sts2-rl-agent](https://github.com/SJTUHCL10/sts2-rl-agent) — a GitHub fork of the above (confirmed via API `fork: true`, `parent: zhiyue/sts2-rl-agent`), 0 independent stars, last pushed 2026-09-21.
  - [HIX4123/sts2-simulator](https://github.com/HIX4123/sts2-simulator) — "Slay the Spire 2 headless Python simulator", small repo (0 stars, last pushed 2026-09-12); did not fetch contents in depth, treat as unverified/minor.
  - [wuhao21/sts2-cli](https://github.com/wuhao21/sts2-cli) — "Headless Slay the Spire 2 CLI — play the full game from a terminal", 265 stars, last pushed 2026-09-07; description claims damage/card effects/enemy AI/RNG identical to the real game. Not independently verified beyond repo metadata/description.
  - [Gennadiyev/STS2MCP](https://github.com/Gennadiyev/STS2MCP) — not a simulator but a live-game bridge (500 stars, last pushed 2026-07-29); see §1 and §4.
  - [ptrlrd/spire-codex](https://github.com/ptrlrd/spire-codex) — a static reference database/API built by decompiling the shipped `.pck`/C# DLL (ILSpy). Exposes card/relic/monster/event/etc. data and monster AI patterns extracted from source, plus a community run-upload/leaderboard system. Explicitly **not** a live-game interface: no live state access, no RNG/seed manipulation, no headless play — read-only static reference only. [ptrlrd/spire-codex](https://github.com/ptrlrd/spire-codex)
- No StS1-analogous "CommunicationMod" standard protocol was found for StS2; STS2MCP's localhost REST API (port 15526) is the closest existing thing.

## 3. Seeded RNG

- StS2 RNG is deterministic and seed-based: the same seed reproduces the same card offers, events, relics, and bosses. Seeds are entered as 12-character alphanumeric codes from a "Custom Game"/"Custom Run" menu and are case-sensitive. [sts2-calculator.com RNG seed guide](https://sts2-calculator.com/rng-seed-guide/)
- The RNG implementation itself changed mid-early-access: Major Update 2 (v0.107.1, June 19 2026) included an "RNG rework" after community-reported bias (e.g., overly frequent "Debt" from Neow's Bones). Mega Crit programmer Ed Lu described the new RNG as "evenly distributed" with "no human-detectable correlation." Determinism-per-seed was preserved, but seeds generated before the rework do not reproduce the same results under the new generator — pin game version alongside any seed. [PCGamesN](https://www.pcgamesn.com/slay-the-spire-2/update-2-rng-rework-steam-workshop)
- Enemy move/intent patterns: spire-codex's decompilation documents monster AI as C# state machines (112 monsters cataloged with cycle/random/conditional AI), implying intents are computed from the same seeded RNG stream and thus deterministic per seed, consistent with StS1 behavior — but this inference is from a decompiled reference site, not a primary Mega Crit statement. [spire-codex.com](https://github.com/ptrlrd/spire-codex)
- Seed-exploration/search tooling exists in the community (searchtheseed.com, searchthespire.app) implying practical, real-world reliance on determinism, though these weren't fetched in depth for this report.

## 4. Public bots/RL agents

- [zhiyue/sts2-rl-agent](https://github.com/zhiyue/sts2-rl-agent): reported results per its own README — MaskablePPO-trained agent reaches ~92% combat win rate on Act 1, Ironclad, in its headless simulator (not verified independently, and not a full-run/ascension-level result; no reported ascension level or full-run win rate found).
- [Gennadiyev/STS2MCP](https://github.com/Gennadiyev/STS2MCP): framed as "an experimental research project to fully-automate your Slay the Spire 2 runs," designed to let LLM agents (e.g. Claude via MCP) play live via its REST/MCP bridge. No reported win rate, ascension level, or benchmark numbers found in the README excerpt reviewed.
- A dev.to post ("I made an agent play Slay the Spire 2 on its own…") describes an agentic approach but no quantitative results were pulled from it. [dev.to](https://dev.to/brmarcosbr/i-made-an-agent-play-slay-the-spire-2-on-its-own-and-what-unlocked-it-was-the-game-saying-no-2hc2)
- An arXiv paper "AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents" surfaced in search; not fetched/verified whether it targets StS1 or StS2 specifically, or what results it reports. unknown / could not find confirmed StS2-specific benchmark numbers from this source — treat as unconfirmed. [arXiv](https://arxiv.org/pdf/2607.02255)
- No peer-reviewed or Mega Crit-endorsed StS2 RL benchmark (analogous to the StS1 academic RL papers) was found. Overall public StS2 bot landscape is early, hobbyist/community-scale, with no reported ascension-level clears or full-run win rates beyond the isolated Act-1 combat number above.

## 5. Release status

- Early access, not fully released, as of 2026-09-21. Launched March 5, 2026 for Windows/macOS/Linux; no full-release date announced. [Wikipedia](https://en.wikipedia.org/wiki/Slay_the_Spire_II)
- Mega Crit has explicitly declined to commit to a patch-cadence timeline: "it's not what works for us." In practice, patches have shipped roughly every few weeks to about a month, first on a public beta branch then merged to the main/stable branch (e.g. Mega Crit's own X posts confirming beta-branch patches subsequently going live on main). Current patch train as of the wiki.gg patch-notes page (last updated 2026-09-10) is in the v0.110–v0.111 beta-patch range. [Mega Crit on X (patching methodology)](https://x.com/MegaCrit/status/2035125930876678627), [Mega Crit on X (beta→main promotion)](https://x.com/MegaCrit/status/2034012515538202975), [wiki.gg Patch Notes](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Patch_Notes)
- Ascension mode exists, max level is Ascension 10 (not 20 like StS1). Levels stack cumulatively; A10 ("Double Boss," fight two Act 3 bosses) is the current hardest tier and requires clearing an Act 3 boss on A9 first. [wiki.gg Ascension page](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Ascension)
- Steam Workshop mod support (official) shipped June 19, 2026 with Major Update 2 (v0.107.1); the Workshop was described by Mega Crit as "a little barebones" at launch but expected to grow with community engagement. [PCGamesN](https://www.pcgamesn.com/slay-the-spire-2/update-2-rng-rework-steam-workshop)
